# Memory Index

Durable knowledge for LP Ranger that is **not derivable from the code**.
Scan the hooks, open only what you need. `feedback_*` = how the user wants
work done, treat as rules. `project_*` = state, decisions, open items.
`reference_*` = external pointers.

**New here? In this order:** [project_renamed_lp_ranger](project_renamed_lp_ranger.md)
(what this is) → *Workflow, git & CI* (the rules that bite first) → *How to
work with the user*. The repo's `CLAUDE.md` covers architecture; this covers
everything else.

Also: `private/` holds machine-local memories (infrastructure, addresses, live
position figures) that are gitignored and do not travel — a fresh clone starts
without them. `archive/` holds resolved history, deliberately not indexed.
