> **First-time install:** Download **both** assets below: `lp-ranger-<version>.tar.gz` (the large ~10 MB file; **not** "Source code") and its `lp-ranger-<version>.tar.gz.sha256` companion. Verifying the tarball against that checksum before you run it is strongly recommended &mdash; this software holds the keys to real funds: https://github.com/nottoseethesun/lp-ranger#optional-verify-download . Then follow the **Production** install instructions: https://github.com/nottoseethesun/lp-ranger#install
>
> **Updating an existing install?** Do **NOT** follow the Install instructions. They assume a clean directory and would create a separate versioned install rather than upgrading your current one. Follow the **Update** section instead, which preserves your wallet, managed positions, and any custom overrides while replacing only the shipped code and shipped defaults: https://github.com/nottoseethesun/lp-ranger#update
