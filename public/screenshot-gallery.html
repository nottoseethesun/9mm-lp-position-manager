General

Here you can see LP Ranger really doing its job! The user has rebalanced too many times. That's because the user is the dev, and there isn't a complete toolchain on testnet, so he's doing the Only Way to Fly, “Testing in Production”. But you can see the impact of that on Impermanent Loss/Gain.

Bot Configuration

Everything that governs how the bot behaves on a position, set per position and saved field by field: when a rebalance triggers, how often one is allowed to, the range and slippage it works within, and the contracts and RPC it talks to. Every row carries a circle-i explaining what the setting does and how to tune it.

Action Dialogs

Dialogs you act in, rather than merely read: each one either changes app state through a form control, or asks you to work a dynamic list and decide from it. They share a common shape — title top-left, a “Close” button at the top right, and any primary action at the bottom.

Settings Dialogs

Dialogs for configuring LP Ranger itself and its integrations.

Info Dialogs

Click the circle-i next to any parameter for in-app help on what it does and how to tune it.

Responsive Design

LP Ranger's dashboard adapts to smaller viewports, collapsing to a single-panel-per-row layout below 1981px so each card remains readable on laptops, tablets, and phones.
